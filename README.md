# Tarefas

Quadro de tarefas estilo Trello para a equipe: colunas, cartões arrastáveis, responsáveis, prazos, prioridades e etiquetas (BUG, REMOVER, ADICIONAR, SUGESTÃO, DESIGN, REUNIÃO, MARKETING).

É uma página única (`index.html`), sem build. Para ver o site, ative o GitHub Pages em Settings, Pages, branch `main`, pasta `/ (root)`.

Os dados ficam salvos no navegador de quem usa. Para a equipe compartilhar o mesmo quadro é preciso ligar um banco de dados online.
